1. - std::set

用途：有序集合，元素唯一，自動排序（預設升序）。

頭文件：#include

基礎用法：


std::set s;
s.insert(3); // 插入
s.insert(1); // 自動排序 {1, 3}
if (s.find(3) != s.end()) {
    std::cout << "Found 3\n";
}
s.erase(1); // 刪除

特點：紅黑樹，O(log n) 插入/查找/刪除，元素去重。

考試注意：若無排序需求，用 std::unordered_set（O(1) 平均）。

優缺點：自動排序 vs. 較慢於 unordered_set。

2. - std::unordered_map

用途：鍵值對映射，鍵唯一，無序，哈希表。

頭文件：#include

基礎用法：


std::unordered_map m;
m["apple"] = 5;
m.insert({"banana", 3});
if (m.find("apple") != m.end()) {
    std::cout << m["apple"] << "\n"; // 輸出 5
}
m.erase("banana");

特點：平均 O(1) 插入/查找/刪除，鍵需支援哈希。

考試注意：m[key] 簡潔，m.at(key) 提供越界檢查。

優缺點：快速查找 vs. 無序，記憶體開銷大。

3. - std::vector

用途：動態陣列，支援隨機存取，動態調整大小。

頭文件：#include

基礎用法：


std::vector v = {1, 2, 3};
v.push_back(4);
v.pop_back();
std::cout << v[1] << "\n"; // 輸出 2
for (auto it = v.begin(); it != v.end(); ++it) {
    std::cout << *it << " ";
}

特點：連續記憶體，隨機存取 O(1)，中間操作 O(n)。

考試注意：避免越界，v.at(i) 比 v[i] 安全。

優缺點：靈活 vs. 中間操作效率低。

4. 虛擬函數與覆蓋

用途：實現多型，子類重寫基類方法。

頭文件：無需額外頭文件。

基礎用法：


class Base {
public:
    virtual void func() { std::cout << "Base\n"; }
    virtual ~Base() = default;
};
class Derived : public Base {
public:
    void func() override { std::cout << "Derived\n"; }
};
int main() {
    Base* ptr = new Derived();
    ptr->func(); // 輸出 Derived
    delete ptr;
}

特點：虛表實現動態分派，override 確保正確覆蓋，虛擬析構避免記憶體問題。

考試注意：基類析構需為虛擬，否則未定義行為。

優缺點：支援多型 vs. 虛表有性能開銷。

建議：簡單題目避免複雜繼承，優先簡單實現。

5. - std::sort 等

用途：排序、查找、操作容器。

頭文件：#include

基礎用法：


std::vector v = {3, 1, 4, 1, 5};
std::sort(v.begin(), v.end()); // 升序 {1, 1, 3, 4, 5}
std::sort(v.begin(), v.end(), std::greater()); // 降序
std::sort(v.begin(), v.end(), [](int a, int b) { return a > b; }); // 自訂

其他功能：std::find, std::min_element, std::max_element, std::reverse, std::unique。

考試注意：確保迭代器範圍有效，小數據量可手寫冒泡排序。

優缺點：高效（O(n log n)） vs. std::sort 非穩定。

建議：優先 std::sort，穩定排序用 std::stable_sort。

6. , - 字串分割

用途：按空格分隔字串到 std::vector。

頭文件：#include , #include

基礎用法（stringstream）：


std::string input = "hello world test";
std::vector words;
std::stringstream ss(input);
std::string word;
while (ss >> word) {
    words.push_back(word);
}

替代方法（手動解析）：


std::string input = "hello world test";
std::vector words;
size_t start = 0, end;
while ((end = input.find(' ', start)) != std::string::npos) {
    words.push_back(input.substr(start, end - start));
    start = end + 1;
}
if (start < input.length()) {
    words.push_back(input.substr(start));
}

考試注意：stringstream 簡單，處理多空格；手動解析無需 。

優缺點：stringstream 易用 vs. 手動解析靈活。

建議：優先 stringstream，考試時間有限。

7. - std::invalid_argument, 異常處理

用途：拋出/捕獲錯誤，特別是參數無效。

頭文件：#include

基礎用法：


void processNumber(int x) {
    if (x < 0) throw std::invalid_argument("Negative number not allowed");
    std::cout << "Processing: " << x << "\n";
}
int main() {
    try {
        processNumber(-5);
    } catch (const std::invalid_argument& e) {
        std::cerr << "Error: " << e.what() << "\n";
    }
}

其他方式：返回值檢查，assert（#include ）。

考試注意：簡單題目用返回值檢查，複雜題目用異常。

優缺點：異常明確 vs. 性能開銷大。

建議：參數檢查用 std::invalid_argument，簡單題目用返回值。

8. - 浮點數精度

用途：控制 std::cout 浮點數輸出格式。

頭文件：#include

基礎用法：


float num = 3.14159;
std::cout << std::fixed << std::setprecision(2) << num << "\n"; // 輸出 3.14

替代方法（printf）：


printf("%.2f\n", num);

其他功能：std::setw(n), std::left, std::right, std::scientific。

考試注意：std::fixed 需 ，printf 無需頭文件，float 精度限 6-7 位。

優缺點：std::fixed 標準 vs. printf 簡單。

建議：優先 std::fixed，簡單題目用 printf 節省時間。

9. - 時間處理

用途：計時、時間差計算，跨平台高精度。

頭文件：#include

基礎用法：


auto start = std::chrono::high_resolution_clock::now();
// 操作
auto end = std::chrono::high_resolution_clock::now();
auto duration = std::chrono::duration_cast(end - start);
std::cout << "Time: " << duration.count() << " ms\n";

其他功能：sleep_for, nanoseconds, microseconds, seconds。

考試注意：確認題目需計時，C++11 以上支援。

優缺點：精確 vs. 語法稍複雜。

建議：簡單題目用迴圈計數，複雜題目用 duration_cast。

10. - std::array

用途：固定大小陣列，替代 C 風格陣列。

頭文件：#include

基礎用法：


std::array arr = {1, 2, 3, 4, 5};
std::cout << arr[2] << "\n"; // 輸出 3
for (auto& x : arr) {
    std::cout << x << " ";
}

特點：編譯期固定大小，支援越界檢查（at()）。

考試注意：需動態大小用 std::vector。

優缺點：安全 vs. 大小不可變。

11. - 數學運算

用途：三角函數、指數、對數、取整等。

頭文件：#include

基礎用法：


double x = 3.14159, y = -4.7;
std::cout << std::sin(x) << "\n"; // 正弦
std::cout << std::cos(x) << "\n"; // 餘弦
std::cout << std::sqrt(16.0) << "\n"; // 平方根
std::cout << std::pow(2.0, 3.0) << "\n"; // 2^3
std::cout << std::abs(y) << "\n"; // 絕對值
std::cout << std::floor(y) << "\n"; // 向下取整
std::cout << std::ceil(y) << "\n"; // 向上取整
std::cout << std::round(y) << "\n"; // 四捨五入
std::cout << std::max(5.0, 3.0) << "\n"; // 最大值
std::cout << std::min(5.0, 3.0) << "\n"; // 最小值

錯誤檢查：


if (x < 0) throw std::invalid_argument("sqrt requires non-negative input");
std::cout << std::sqrt(x) << "\n";

考試注意：檢查輸入範圍，M_PI 可能需 _USE_MATH_DEFINES，簡單題目手寫邏輯。

優缺點：功能豐富 vs. 無內建錯誤檢查。

建議：搭配 std::invalid_argument，簡單題目手寫邏輯。

考試環境建議

  • 確認 g++ 或 clang++ 支援 C++17（g++ -std=c++17）。
  • 準備模板代碼（如 std::sort、std::fixed）。
  • 優先高效方法（如 std::sort 替代手寫排序）。
  • 簡單題目用返回值檢查，複雜題目用 std::invalid_argument。
